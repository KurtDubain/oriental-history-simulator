# 《沧衡纪》三主循环与功能归属台账

> 状态：v1.3.0 已接通“关注人物 → 入世定一事 → 季度裁决 → Fact/记忆/传记/权势反馈”的首条可玩闭环；LOOP01 总门禁仍待 EMB06 的同类 AI/玩家统一裁决与 EMB08 防滥用审计后关闭，2026-08-27
> 原则：历史记录是行动结果的投影，不是独立玩法；后台模拟可以复杂，玩家入口必须少而连贯。

## 1. 三条玩家主循环

### 天下供养

```text
生产与环境压力 → 人口/粮食/财富 → 财政与供养 → 战争/贸易/灾害消耗
→ 迁徙、疾病与地区兴衰 → 下一季生产条件
```

玩家只需要判断哪里在兴盛、哪里正在被透支、什么压力可能改变局势。贸易、疾病、迁徙、知识和海权是这条循环的信号与条件，不成为五套独立管理游戏。

### 人物权力

```text
经历、欲望、家族、官职 → 形成目标 → 积累支持并采取行动 → 机构回应
→ 官职、军权、关系、派系资源改变 → 新处境与新目标
```

这是下一阶段的主要可玩纵切。人物必须真正做事，国家、家族、派系和军队必须回应；只展示人物属性、派系数值或历史摘要不算交付。

### 观察与入世

```text
具体事实 → 当世问题/Situation → 关注或代入 → 等待或提交一项人物行动
→ 共用 Resolver 结算 → 地图、档案、传记与世界史同步反馈 → 下一观察点
```

地图、当世三问、局势卷宗、人物档案和史册是同一事实的不同阅读深度，不各自编写另一种真相。

## 2. 现有玩家入口归属

| 现有入口 | 主要循环 | 产品角色 | 收口决定 |
|---|---|---|---|
| 顶栏季度推进、自动演化 | 天下供养 | 主循环交互 | 保留为全局唯一时间入口 |
| 舆图、地区速览、人口/粮食叠层 | 天下供养 | 主循环交互 | 地图先回答哪里变了，再跳同一件事 |
| 贸易、迁徙、疾病、知识、海权叠层 | 天下供养 | 后台信号 | 不新增独立导航或管理页，只在相关压力出现时显露 |
| 本季变化与季度总账 | 天下供养 | 合并入口 | 只保留本季净变化、具体事件和下一追问 |
| 人物、世家、列国、军旅名录 | 人物权力 | 合并入口 | 继续共用“名录→档案”，不再增加平行名册 |
| 人物所图、人生记忆、关系与官职 | 人物权力 | 主循环交互前置 | 必须接入真实 Intent/Resolver；不能长期停留在只读解释 |
| 国家朝堂、派系与权臣 | 人物权力 | 主循环交互前置 | 用可解释权势资源账接收行动后果，不独立做数值看板 |

| 历史工作台、人物传记、国史、家族史 | 观察与入世 | 结果投影 | 复用同一 Fact 场面；不以新增筛选器作为玩法进度 |

| 版本与检查更新 | 产品基础设施 | 辅助能力 | 留在观察台卷末刊记，只有新版本时提示 |

## 3. 首条统一人物权力纵切

下一条代码交付固定为：

```text
战功、关系与家族地位形成“需要支持”的压力
→ 将领主动提携副将、联络军中同僚或请求家族背书
→ 支持来源成为可消耗、可失去、可追溯的权势资源
→ 将领请领独立军令
→ 君主/主将批准、拒绝、削权或安抚
→ 官职、军团控制、关系、声望与派系权势发生权威变化
→ 产生具体 Fact、人生记忆、Situation 转折和下一观察点
→ 玩家可继续观察；EMB 接入后也可代入人物提交同类 Intent
```

### 第一批只做这些行动

1. `联络将校`：副将投入一季心力与少量私人资财联络本军将校；成功形成可追溯军中支持，失败则只留下实际付出的成本和经历。
2. `请求背书`：人物向家主、主君或现任主将请求明确支持；对方可以支持、拒绝或暂缓，并留下关系记忆。
3. `请领军令`：复用已有 C10/C11 权威请求；支持不再只是等待数值自然达到，而来自前两项已结算行动。
4. `安抚或削权`：机构针对高风险人物作出回应；先不接入公开叛乱，避免一次铺开完整王朝循环。

### 暂不增加

- 不增加新的历史筛选页、人物百科页、派系卡片墙或独立“任务中心”。
- 不增加自由行动菜单；人物只看到与职位、目标和当前资源相符的少量行动。
- 不同时扩展海军副将、围城、宗教、文化、兵种和资源。
- 不先制作更多 Situation 类型；现有军权危机承接本纵切的形成、升温与结案。

## 4. 纵切完成判据

- 固定种子中至少一名人物能主动完成“积累支持→请令→机构回应”，不依赖人为修改数值。
- 至少存在获准与未准/削权两条结果路径，均由同一 Resolver 结算并能精确复演。
- 支持必须能展开到具体人物、家族、官职或军令；禁止继续使用无法解释来源的单一总值。
- 行动结果必须反馈到下一季人物目标、关系、任职与军权危机，而不是只写入一条史册文字。
- 当世三问、地图/档案速览、人物经历和局势卷宗对同一行动使用相同主语、对象与结果。
- 玩家在默认界面能回答“他想做什么、依靠谁、刚做了什么、机构如何回应、接下来观察什么”。

## 5. 新功能准入模板

以后任何功能进入 Roadmap 前必须填写：

```text
主循环归属：
压力来源：
行动者与意图：
消耗的真实资源：
唯一 Resolver：
权威状态变化：
下一季反馈：
玩家从哪里看到/介入：
若不实现，它能否退为后台信号：
```

无法填写“行动者、Resolver、状态变化、下一季反馈”的内容，不作为新玩法开发。
