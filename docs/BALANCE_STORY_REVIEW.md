2026-09-08，未提交、未发布。基于 HEAD 5fdea90 及已存在的 v1.29.3 UI 工作树；完整保留此前未提交改动。本轮授权修改模拟，不能与上一轮 UI 的“世界结果冻结”混为一谈。

## 已确认的根因与实际修改

1. **进攻判断**：此前主要按距离、目标价值选地，截击只比较一支敌军；实际防守却汇总同地军队。现在陆路目标和截击共用近边境守军总量、地形城防、己方准备、近8季败战报告。只见过旧报告时用旧报告，不读取远方隐藏守军的健康、能力或补给。谨慎与野心保留冒险差异。不利时现有军令可改目标、留守或撤回；原有援军依然必须真正移动到前线，不假装共同进攻。
2. **停战**：旧开战冷却从开战之季算起，久战结束就失效。现在另从最近停战算起，至少4季后才考虑重启，并检查厌战、国库、部队补给。没有新增“撕约”机制，因此也不伪造撕约理由。8季后的财政耗尽、疲惫或实际停滞可以提前收兵；普通赶路与正在准备登陆不误判为停滞。原24季收兵上限保留。
3. **纳贡**：原最低贡额可能超过支付能力。新季贡不超过缔约时国库的八分之一；空国库不能承诺。高信用、能支付至少一半时沿用现有贡赋事件实际减贡，转账守恒；大幅缺款仍违约、损失信任和信誉。重签需等待且有信用、财政基础，不再下一季机械立约。
4. **军功**：删除 engine/登陆/副将职业阶段的重复奖励。胜方参战者获得功绩，指挥者承担额外荣誉和败战责任；败方副将增长经验，但不凭参战领取功绩。实际 Battle Fact 记录每人的奖励和问责变化；显名只能由该场胜仗的真实功绩跨越产生。不虚构尚未模拟的断后救援功劳。
5. **重大败局**：主将声望与影响按实际损失下降；近8季损失达三成的败战会打开现有副将请令条件之一，其他履历、支持、权限仍须满足。不是“一败就撤”。战死风险去掉重复幂次压低，仍依实际损失、战场暴露、身份、健康和谨慎决定，上限没有提高。原负伤退营、休养、康复和死亡唯一清理链继续使用。
6. **摄政**：不增加摄政账本，现有宰辅承接实际执政者。幼主不再直接以自身属性决定日常政治与宣战；宰辅死亡或不再在本国任职时重新选择。成年后切回君主，留下还政经历和恩义，既有军队、职位不随文案凭空转移。异姓接掌空缺君位称继承/拥立，不再冒称推翻在位君主。
7. **和平人物**：调查发现赈济、减税已经真实影响库存、财政、动荡、个人功绩和影响，并非只有文案。此次只让实际施政和重要文官任免进入人物关键经历；婚姻、谱系、承诺继续沿用已有领域后果，不增加和平技能树。

- `fact_0000304`，T9齐州战败：高嘉璋率泉州中军9,874人，损失2,184；本人声望35→33、影响18→16；副将卫嘉直只增加经验24→28，没有败战军功。
- 随后的真实胜仗继续积累战绩。T16，`fact_0000476`记录卫嘉直请求获准，两人主副将互换。这一任用有自己的履历、支持和朝廷回应事实，**不能仅因它发生在败战之后，就说T9单独导致撤职**。
- T64 `fact_0001170`又败于辽东，卫嘉直所统行营9,487人损失2,288；T67 `fact_0001246`记录高嘉璋以既有履历和真实背书再次请令获准，重掌军令。旧部实际拥戴与法定主帅不是一个字段，换帅没有自动抹掉旧部关系。

这里能证明的是兵力、经验、声望、支持和权限变化进入下一次现有任用裁决，不是补写“暗中怀恨、蓄谋复仇”。

已知限制，不以“全部平衡完成”掩盖：

1. 强国更善于避开硬点后可能扩张更快：参赛留验最大国家25→40/68地区，私人留验16→33/82地区。没有调高守军、调低攻方来凑胜率，也没有加入反强国机制；需要更多样本观察集中度。仍有目标11次跨战连败，不能宣称重复失败消失。
2. 攻击仍单行营结算、防御同地汇总；没有共同进攻、围城、俘虏或赎回系统。新守军评估主要约束陆路行动，宣战的原战略军力估计与登陆判断未全面重写。
3. 和平保留一年最低间隔和原24季收兵上限；没有撕约/延期等新外交生命周期。纳贡实现了实际减贡和信用约束，未做独立谈判界面。
4. 摄政使用现有职位权限与既有政治冲突，不是完整的“拒绝还政、摄政制度改革”系统。失去在世/本国身份或现有职位变动可更换人选；没有另造摄政者每季争权AI。
5. 败中救援、战术贡献等尚无权威事实，不能据此颁功。当前经验/军功仍是简化评价，不是假装已逐人模拟战术贡献。
6. 关键经历仍可能偏重几次战胜，密集地图仍有标签拥挤；不在本轮扩成叙事生成器或地图布局重写。
