# 第一批媒体接入约定

v1.29.26 已接入五个原创短音效、两张生成式装饰图。不是背景音乐、人物肖像或新的信息面板。技术播放与失败回退已验证；主观听感、真实 iOS 静音键行为仍待人工确认。

## 目录与来源

- 文件放入 `public/media/sfx/` 或 `public/media/images/`，小写英文语义名、连字符；音效用 Ogg/MP3/M4A，图片用 WebP/AVIF。
- 每个文件必须登记到 `media/manifest.json` 的 `assets`，字段：`path`（如 `media/sfx/quarter-turn.ogg`）、`kind`（`sfx`/`image`）、`load`（`initial`/`lazy`）、`source`（原始来源 URL 或创作源文件）、`creator`、`license`（授权类型及授权凭据路径/URL）。不得登记虚假授权；来源不清不进入产物。
- 原稿、授权凭据和压缩工作文件不放 `public`。同一声音可供多类真实事件复用，不按每位人物制作资源。

## 统计与加载

- 首批约6—8个音效，实际编码文件总字节≤250 KiB；约8—12张图片≤800 KiB；两类合计≤1 MiB，首屏≤150 KiB。文件按原始传输正文计，不用二次gzip虚报收益；JS/CSS仍单独跑原门禁，包括全部异步chunk。
- `npm run check:media -- dist` / `dist-contest` 检查源文件、产物、清单、种类/总量/首屏预算及大块base64内联。源码以URL引用资源，不import二进制进入JS；后续首屏实际网络请求也必须与`load`声明核对，不能只靠清单通过。
- 仅首屏确实可见的必要图片可标`initial`；案卷/人物插图在玩家展开对应内容时加载。音效在明确手势启用之后才按需加载，不随创建世界批量预下载。禁止预取全部媒体。
- 当前项目没有注册Service Worker或PWA预缓存。本轮不新增；若以后引入，媒体默认排除在安装预缓存外，并再次核验安装请求总量和离线回退，不许直接glob全部public资源。

## 首批实际资源与触发

- `quarter-step.mp3`：手动推进且没有重大提示时的轻落季声；自动演变不逐季敲击。
- `folio-open.mp3`：主动打开史册、案卷、史事证据；读旧事只响翻卷，不重播事件音。
- `battle-seal.mp3`：刚结算的重要领土变化或停战；不是每次会战广播。
- `accession.mp3`：刚结算的重要继位、监国；`farewell.mp3`：重要死亡或亡国。只取当前实际结算的 Fact/Event，沿用其重要性，不产生或修改事实。
- 同季最多一种，死亡/亡国、继位/监国、战局依次择一；实际结算入口去重，不能从组件渲染、案卷历史或导入回放触发。手动提示间隔至少350ms、自动至少3秒、翻卷至少700ms；单声部，没有积压队列。加载超过1.2秒的过时提示直接丢弃。
- `river-margin.webp`：世界书页右下淡墨山水，首屏17,452B；`river-seal.webp`：史册/案卷既有章首印纹，按需3,786B。两图共21,238B，五音效39,498B，媒体合计60,736B；只是本批实际用量，不证明未来全部媒体也已通过。

## 运行时与验收边界

- 现有设置中的“提示音”默认关闭，音量默认40%；开关、音量、书页装饰仅存浏览器偏好。记住开启也不会在刷新时突响，须本次页面的真实手势解锁 AudioContext。背景/离页停止，切换或导入世界使旧待播任务失效，不补播历史；手动启用不会自动试听。
- 一个 AudioContext、一个声部、最多五个可重建解码结果；没有持久事件簿或世界快照。静音/零音量立即停止；加载、解码、恢复播放失败无声降级，不阻断推进，失败资源不逐季重试。再次刷新页面才重新尝试失败资源。
- 图是既有区域的 CSS 背景/伪元素，不增加高度、正文行数或地图层；缺图保留纸面、文字与原 SVG。关闭“书页装饰”不影响任何入口，不新增动画，原减少动态设置不变。
- `npm run test:e2e:media` 运行真实生产浏览器（可指定 `OHS_E2E_URL`），实际解码与 Analyser 音频输出、静音、刷新记忆、快速演变、导入不补播、证据往返、网络按需请求均有断言。资源阻断专项、T336/T400只读与恢复及桌面/手机截图见 `output/first-media-v1.29.25/REPORT.md`（目录按开工版本）。
- 五个最终 MP3 均通过 Chromium 非零PCM/峰值检查与本机 afplay 顺序播放。代理无法可靠听到主机声音，因此不以“播放成功”代替主观试听；真实 iOS、设备硬件静音/外接音箱尚未验收。下一步只需人工试听确认/必要微调，不借机扩大机制或媒体数量。
- 来源与重新制作步骤见 `media/SOURCES.md`、`media/sources/`。首版 AAC 因 Chromium 解码失败已替换为 MP3；临时离线编码器不进入项目依赖或产物。没有待授权素材、占位图或空音频。
