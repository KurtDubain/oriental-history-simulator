# 第一批媒体接入约定

工程准备，不是已完成的美术或音频实现。尚未选择或生成任何资源。

## 目录与来源

- 文件放入 `public/media/sfx/` 或 `public/media/images/`，小写英文语义名、连字符；音效用 Ogg/MP3/M4A，图片用 WebP/AVIF。
- 每个文件必须登记到 `media/manifest.json` 的 `assets`，字段：`path`（如 `media/sfx/quarter-turn.ogg`）、`kind`（`sfx`/`image`）、`load`（`initial`/`lazy`）、`source`（原始来源 URL 或创作源文件）、`creator`、`license`（授权类型及授权凭据路径/URL）。不得登记虚假授权；来源不清不进入产物。
- 原稿、授权凭据和压缩工作文件不放 `public`。同一声音可供多类真实事件复用，不按每位人物制作资源。

## 统计与加载

- 首批约6—8个音效，实际编码文件总字节≤250 KiB；约8—12张图片≤800 KiB；两类合计≤1 MiB，首屏≤150 KiB。文件按原始传输正文计，不用二次gzip虚报收益；JS/CSS仍单独跑原门禁，包括全部异步chunk。
- `npm run check:media -- dist` / `dist-contest` 检查源文件、产物、清单、种类/总量/首屏预算及大块base64内联。源码以URL引用资源，不import二进制进入JS；后续首屏实际网络请求也必须与`load`声明核对，不能只靠清单通过。
- 仅首屏确实可见的必要图片可标`initial`；案卷/人物插图在玩家展开对应内容时加载。音效在明确手势启用之后才按需加载，不随创建世界批量预下载。禁止预取全部媒体。
- 当前项目没有注册Service Worker或PWA预缓存。本轮不新增；若以后引入，媒体默认排除在安装预缓存外，并再次核验安装请求总量和离线回退，不许直接glob全部public资源。

## 下一轮音画实现必须验证

- 声音默认不自动播放。首次明确点击启用后才能恢复AudioContext；遵守总静音/音量与用户偏好，失去可播放条件时保持无声。
- 以真实Fact/Event身份去重播放，同类同季合并，8×推进不积压播放队列；打开历史证据、导入、重渲染不能重播旧事件。无额外模拟状态。
- 图片失败保留现有文字与布局；音频缺失、解码或播放被拒绝时无声退化、不阻断演变、不循环重试或抛出未处理异常。启用、静音、调音量、后台返回、资源404需真实浏览器验收。
- 桌面/手机首屏及按需网络测量、静音和失败回退尚未实施；零资源通过只证明检查器就绪。未验证前不把P1/P2/P3或媒体运行时验收勾选完成。
