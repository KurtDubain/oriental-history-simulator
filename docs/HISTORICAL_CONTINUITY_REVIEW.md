# 历史合理性与长期因果闭环：修订与验收

2026-09-08。基线 `fe36818` / v1.29.3；当前工作树为本地 v1.29.4，未提交、未推送、未发布。保留了原有 `progress.md` 的百年只读审计记录。本轮修改模拟规则，因此不能声称与旧版本的世界输出相同；保证的是新规则下相同种子、相同操作可重放，以及 schema 5 旧档能够继续运行。

## 结论

粮食困境不是单纯灾荒：人口与产粮同比下降、低价向下取整锁死、粮食交易候选截断共同堵住了恢复路径；治理又把短期降动荡直接当成功绩。这条链已经作了实际修订。战争开局现在检查能走到、能供养的目标，旧的停战恢复期没有删除。背景人才不再靠无限积累机会压过年轻人，占领无成建制守军地区不再等同击败敌军主力。

这不是一次“所有问题已经平衡”的交付。连续攻坚失败、海岛国家缺少主动跨海战争、部分任职入口绕过亡国者接纳条件，以及手机战线被摘要遮挡仍有明确限制。两项浏览器专项未通过，完整 release gate 未运行，不应直接当成发布验收全绿。

## 1. 核实的问题与修改

### 粮食、财政与治理

- 旧产粮直接乘当前人口：在低生产率地区，死亡与迁出同时减少劳力，不能改善人均供需。现在以地图原有 `populationBase` 作为固定土地规模代理，产出劳力项为 `min(人口×2, sqrt(人口×土地基数))`。土地不会随人口消失，劳力有上限；人口为零产粮仍为零。地形、季节、破坏等既有影响仍参与结算。这是简化的土地—劳力模型，不是完整农业制度。
- 奥州有通往同国关东的陆路，也有港口，不能解释成孤岛不可达。更直接的问题是粮价长期停在6：既有单季15%限幅后再向下取整，`6×1.15`仍回到6，邻州价4，缺口无法变成足够的交易动力。价格现在保留两位小数，沿用原限幅与平滑，不凭空抬价、不改变付款结算。
- 粮食不再被全局前10/12个进出口地区、36个配对或单笔6000数量上限截断；先看真实缺口，再看距离与稳定ID。仍需要出口余粮、进口购买力、可通行路径、共享运力和实际付款，仍有运输损耗、路线容量与512笔Shipment总上限。非粮商品保留原候选与运量限制；共用价格函数的精度修复作用于全部商品。
- 扩大真实粮食候选后曾使P95超过预算。没有重新截断救援候选：沿用已有季度内路径缓存，一次求出同一起点的最短路并复用，仍按原有稳定顺序和边权选择路线，实际运力逐笔保留。缓存不跨季度、不持久化，最终与优化前世界逐一比对。
- 断粮严重时不再把减赋当粮食救援。实际开仓/退款仍支付成本并可短暂安抚，但只有粮食至少能支撑一季，并且近期未重复施政、或本次施政前的动荡确实较上次降低，才增加功绩、影响与合法性。最近八季的判断读取既有治理Fact，不新建政绩账本；仍是有界反馈，并不等同多年因果归功。
- 居民财富超过两季人口规模的部分，每季1%进入既有家庭消费支出；动荡降低税收，动荡与破坏降低既有军团补员。没有取消财产，没有免费调拨，也不保证每地繁荣。新编队初次征募、叛乱动员沿用原规则，不能宣称所有征募入口已经统一。

### 战争可执行性、防线与军功

- 宣战前从实际非装载军团检查士气/补给、通向敌方边境的自有地区路径，以及沿途粮食或随军储粮；在既有近处敌情与败战报告边界内判断是否能接近目标，不读取全国敌军作为全知战术情报。
- 最近一场同双方战争若没有Battle，同样条件下仅等停战冷却结束不再足够；要有停战后的实际移动或新军令，并重新通过目标可执行检查。既有至少四季的停战约束、厌战和财政判断保留。新军令本身仍可能无效，所以这不是“空战已全部消失”。
- 一道未执行的两栖军令不再永久阻止停滞议和；真正已开始的海上行动仍被识别。计划、启航与实际装载共用已有最低可装载兵力口径，要求真实舰队和海路，没有伪造跨海协同。
- 防守目标加入实际敌军相邻的自有地区，避免只盯开战时固定目标。战斗公式未改，仍是单个进攻编队与同地守军结算，没有新增合兵进攻。
- 战胜成建制敌军保留既有贡献奖励；仅克服地方防御的占领只给主将1功绩，成员不刷军功、不增加战斗声望。败战不刷军功、指挥问责、伤势休养和个人兵力损失链保留。

### 人才、征服与中央权威

- 背景机会封顶40，不再年复一年攒到100；依据相关能力、年龄健康状况和有界机会选择。不设置青年英雄配额，仍允许75岁以内的既有背景候选出仕，74岁优秀候选的反例测试保留。
- 每地候补人口维持原有有界机制；缺少未成年梯队且名额未满6人时补充已登记背景子代。背景出生不额外增加地区居民人口。取消“本国无人就把外国候补直接搬来”的兜底；无合格者允许职位空缺。
- 新出仕者不再默认获得12军功；晚年出仕的健康按年龄扣减，不能自动当作全盛将领。
- 灭国事件补记接收人物的归属与忠诚变化，不补造赦免或密谋。主帅、地方长官、朝臣和监国候选恢复任用时，要求接收后的时间与忠诚，或现君真实的信任恩义。**副将补缺、部分水师和临阵替补尚未全部接入**，因此不能宣称所有身份恢复都已闭环。
- 领土规模对权威与行政的线性惩罚改成平方根边际负担，仍有规模成本；税收、补员、地方动荡及官僚能力继续起作用。不另加针对强国的隐藏惩罚。权威是中央控制指标，不是“0即全国一切停止”的开关。

### 实机中另外发现的事实验证错误

默认种子浏览器运行曾在T29被运行时校验中断：同季新建的贸易走廊随即被160条保留上限淘汰，事件中的走廊ID在季度前后均不存在。现在只有当该ID的起点、终点和商品能对应本季真实贸易Shipment时才允许这种短暂实体引用；伪造ID仍拒绝。修改的是 `invariants.ts` 校验，不是贸易历史或模拟状态，新增直接反例测试。

## 4. 五条真实人物经历

以下不是补写进游戏的剧情。T为事件的零基季度，名字、代价与结果来自各世界的Fact/Event；没有补写人物心声或把前后相随当成因果。

### 卢德信：安抚执行了，不代表政绩已经成立

私人长风换世-新验，雍国灵州，人物 `c_062`，完整资料 `after/10-T240.json`。

T18，灵州仅有0.56季口粮，卢德信开仓992，库存30,879→29,887，动荡76.73→66；实际发粮，但没有因此增加军政功绩（`fact_0000576`）。T22、26、30以及34～42的退款或开仓继续花钱粮，动荡又多次回到99；这些不能累积为“长期治理成功”。T54，口粮已达1.15季、施政前动荡85.79，退款1,660确实从国库进地方，动荡降至77，功绩9→10、合法性67→68（`fact_0001018`）。T58口粮再不足一季，虽然又退款安抚，却不再记功；T62口粮1.05季且施政前动荡73.49，才再次获得1功绩（`fact_0001089`）。

改变的是“同一种办法能不能继续得到政治认可”，不是声称减赋生产了粮食；粮食改善还涉及真实收成和贸易，不能全部归卢德信。

### 陆弘廉与赵云岫：幼主继位不等于幼主已经亲自执政

## 5. 未解决、退化与简化边界

1. **连续失败未根治。** 原12局最长同目标失败11→19，出现在参赛长风换世的镜海府攻岚关。军令参考的近期报告有界、部分季度同地多次单编队攻击，仍可能在旧失败记忆过期后重复攻坚。未假装成协同攻击，未靠禁战掩盖。
2. **强国集中度上升。** 12局最大国家领土在8局增加；极值从47/82到53/82。大国权威不再多局归零，但财政和人口改善可能强化扩张。不能由权威数值恢复就宣布帝国平衡完成。
3. **跨海主动战略仍不足。** 海潮、流火、和国仍出现长期无Battle的样本；部分航路与装载路径确实可执行，受控两栖测试也通过，但自然宣战入口仍以陆地目标为主。地理保护与战略入口不足同时存在，未新增海军AI。
4. **接纳条件尚未覆盖所有任职。** 陆弘廉在另一条后续轨迹T216亡国被接收后，同季成为副将（`fact_0002829`）；副将、海军和临阵替补是待统一入口，不应在发布说明写成“亡国者全部必须经过考察”。部曲转移和叛乱沿用既有守恒机制，没有新建投降身份系统。
5. **粮食恢复不等于永远解决饥荒。** 生计仍依赖有价贸易，穷困、断路或无运力时可能失败；没有新增行政调粮或长期救灾机构。地区后续人口残差未全拆成每个来源。
6. **监国仍用既有宰辅职权推导。** 没有新增摄政制度状态。原成年事件中的“官职、部曲不变”仅描述亲政步骤，后续同季度任免可能改变官位；默认叙事将来应避免让这句话覆盖整个季度。本轮报告按任免Fact校正，不虚构清洗。
7. **手机摘要遮挡与旧剧情配额E2E仍失败。** 见验证记录。没有以扩大本轮UI范围或校准固定角色命运来换通过。
